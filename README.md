# podcats-voices

- **Releases › v1**: `podcats-phonon-voices.bin`, the voice pack the Podcats web app imports.
- **`ios/`**: Podcats for iPhone, a native app. It reads scripts aloud with Phonon 31m (Gradium, Apache 2.0) on the phone, prepares episodes in the background, and saves them as .m4a files to the Files app. See [`ios/README.md`](ios/README.md).
- **Releases › ios-build**: the latest unsigned `Podcats.ipa` built from `ios/`, with the logs, test outputs and screenshots of that build.
